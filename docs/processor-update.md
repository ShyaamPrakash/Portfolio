# ASCII processor update

The current hero is a Three.js processor assembly rendered through the ASCII effect. A central die connects to four removable boards: interface/frontend, compute/backend, memory/databases, and hardware/C/C++ systems. Scroll-linked timelines pull each module back briefly, lift it out, hold it while its chapter is readable, and return it to the assembly. The core has a slow change of perspective across the story.

The character grid uses a denser desktop resolution with glyph spacing measured to keep the projected model centered. Mobile uses a lower sampling density and a wider camera framing. Reduced-motion mode keeps the assembly intact and all skill text readable. The pause control stops both module timelines and decorative movement.

The project runway remains horizontal with touch/keyboard/button navigation, no numbered projects, and generic SVG illustrations selected from repository content. The existing red contact ending is preserved.

Local browser captures cover the assembled desktop/mobile hero, a separated module, and the runway. Production compilation and desktop/mobile browser tests are the delivery checks. Supabase owner access and physical-device GPU performance remain outside this review.
